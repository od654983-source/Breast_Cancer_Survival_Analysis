#  Breast Cancer Survival Analysis 

##  Project Overview

This project presents an end-to-end healthcare analytics solution analyzing breast cancer patient survival data. It combines **Python (data preparation & modeling)** with **Power BI (interactive dashboard visualization)** to transform raw medical data into clear, decision-ready insights.

The dashboard highlights clinical factors influencing survival outcomes and allows dynamic exploration through interactive filters.

---

##  Project Objectives

* Analyze survival outcomes of breast cancer patients
* Identify key clinical factors affecting survival duration
* Build a professional, interactive Power BI dashboard
* Demonstrate a complete Python → Power BI workflow

---

##  Dataset Description

Each row represents one patient.

**Main Features:**

* Age
* Race
* Marital Status
* T Stage
* N Stage
* Tumor Size
* Estrogen Status
* Progesterone Status
* Regional Nodes Examined
* Regional Node Positive
* Survival Months
* Status (Alive / Dead)

##  Project Workflow

1. Data cleaning and preprocessing using Python
2. Encoding categorical variables
3. Exporting cleaned dataset to CSV
4. Building Power BI data model
5. Creating KPIs and DAX measures
6. Designing interactive dashboard visuals
7. Extracting actionable insights

---

###  KPI Section

* Total Patients
* Alive (%)
* Average Survival Months
* Average Patient Age

###  Core Visualizations

* Patient Survival Distribution (Alive vs Dead)
* Average Survival by Lymph Node Stage (N Stage)
* Hormone Receptor Impact on Survival
* Tumor Size vs Survival Duration (Scatter Analysis)
* Distribution of Positive Lymph Nodes

###  Interactive Filters

* Race
* Marital Status
* T Stage
* N Stage
* Estrogen Status
* Progesterone Status

---

##  Key Insights

* Hormone-positive patients generally show longer survival periods.
* Higher lymph node stages (N Stage) significantly reduce survival duration.
* Larger tumor size is negatively correlated with survival months.
* Lymph node involvement is a critical prognostic factor.
